NexGen Warehouse audit/update

Critical fixes included:
1. Fixed Expense module database mismatch:
   - Added ExpenseCategory model and Expense.categoryId relation.
   - Added referenceNumber and attachment fields to Expense.
   - Added migration that preserves existing enum-based expense categories and data.
   - Updated expense validation/service/report/dashboard and client form/table for category IDs.
2. Fixed several calculation issues:
   - Purchase subtotal now falls back to item subtotal when totalBill is omitted/0.
   - Purchase due = grand total - paid amount; shipping is not subtracted twice.
   - Prevents discounts greater than subtotal in financial calculations.
   - Dashboard monthly totals no longer add today's amount a second time.
   - Dashboard active invoice counter now uses actual open due invoices.
3. Fixed reporting correctness:
   - Reports/profit/customer/supplier calculations exclude inactive transactions where appropriate.
   - End-date filters include the full selected day for date-only inputs.
   - Low-stock report now correctly counts out-of-stock products instead of always returning zero.
4. Fixed expense category display and recent dashboard activity after the category relation change.
5. Verified all server-side .js files with `node --check`: no syntax errors.
6. Relative client imports were checked: no missing relative imports found.
